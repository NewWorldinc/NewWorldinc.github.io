All About City

AAC is a Singapore-based network of expat and city publications: allabout.city, expat.guide and a shelf of sibling titles. I joined in June 2026 to replace an aging WordPress install with something the business could build on. Four months later it runs on Next.js, Payload CMS and Postgres, serves two brands from one deployment, and the sites never went down.

Content migration

700+ articles out of WordPress, by crawling the rendered pages

The WP API loses Elementor and shortcode content, so I wrote a resumable crawler that treats the rendered page as ground truth: gzipped raw HTML, extracted JSON, a media manifest and a SQLite index. Then a series of dry-run-first repair passes: 4,600+ image nodes converted, 4,300+ repositioned, 2,300+ duplicates removed.

  • Python
  • BeautifulSoup
  • SQLite
  • Lexical

Production discipline

Gated migrations instead of deploy-time surprises

Every schema change ships as a numbered batch with its own runbook: snapshot, dry run, undo log, execute, verify. Migrations never run as a side effect of a deploy, a per-gate token stops scripts touching prod by accident, and a build-info endpoint proves which commit is actually live.

  • Payload migrations
  • SSH tunnels
  • TypeScript scripts

Domain flip and SEO recovery

5,400+ redirects and a cleanup of what Google saw

Cut the apex domain over to the new stack with a bulk redirect list covering the old URL space and a 12-hour watchman monitoring the flip. When rankings dipped, I audited Search Console, built a 404-to-live redirect map, removed dead sitemaps and fixed canonical and trailing-slash drift.

  • Cloudflare Rules
  • Workers
  • Search Console

Second brand, same codebase

Launching expat.guide as a tenant of the platform

Built the nationality-first structure (55 community pages, embassy data, an A-to-Z register) and shipped it as a second site resolved by hostname. The brands share layout components; CSS is split into a structure layer both use and a paint layer each brand owns.

  • Multi-tenant routing
  • Design tokens
  • Editorial tooling

A CMS editors actually use

Payload admin reshaped for non-technical authors

Human labels on every field, navigation grouped the way editors think, live preview of the real site beside the editor, and a paste box that ingests whole markdown articles under a versioned content contract. A publish gate blocks any article that still carries an unverified claim.

  • Payload CMS
  • Live preview
  • Content contracts

Security and the business side

2FA, fail-closed tenancy and the paid-listings pipeline

TOTP two-factor for admin accounts, login lockout, contributors who can't publish, and access rules that fail closed across sites. On the revenue side: a listings directory, a public business-submission form with layered anti-abuse, an approval inbox, and labelled recommended placements on articles.

  • Access control
  • TOTP
  • Click tracking

SC4020 · Recommender systems · Oct 2026

Neural Collaborative Filtering, with the ablation

Group technical review comparing MF, SVD++ and NCF on MovieLens-1M and Amazon Electronics, scored on HR@10 and NDCG@10 against 99 fixed negatives. I owned NCF: GMF, MLP and NeuMF in PyTorch, a grid over factors and learning rate, ablations on depth, negatives and pretraining, three seeds per pick.

Pretrained NeuMF reached HR@10 0.684 on ML-1M, 27 points over popularity. On Amazon every neural model landed within a point of the popularity baseline, which became the most useful finding in the report.

  • PyTorch
  • Implicit feedback
  • Experiment design
